# v1 からの移行

移行前に作業ツリーとローカル設定のバックアップを取り、差分と必要な権限を確認してください。移行計画は対象を分類し、利用者が変更したファイルや競合を表示します。

```sh
seh migrate plan --from v1
```

このコマンドは移行計画を保存し、そのパスを表示します。計画の内容を確認し、対話端末で次を実行します。

```sh
seh migrate apply --plan <表示された計画ファイル>
```

適用時には確認が必要です。競合パスの置換には個別の `--approve-conflict <path>` が必要です。計画後に対象が変わった場合は計画を作り直してください。実行結果に表示された snapshot ID は復旧用に保存します。

```sh
seh migrate rollback <snapshot-id>
```

復元後は `seh doctor` と Git 差分を確認してください。移行対象や競合を理解できない場合は適用を中止し、計画とバックアップを保持してください。
