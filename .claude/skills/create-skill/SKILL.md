# スキル作成

## 手順

### 1. 要件定義

ユーザーにヒアリングして以下を明確化する:

- **目的**: このスキルは何をするか
- **トリガー**: いつ使うか（description に記載する内容）
- **入力**: `$ARGUMENTS` で何を受け取るか
- **出力**: 何を生成・変更するか
- **制約**: 守るべきルールや条件

### 2. テンプレート生成

以下の形式でスキルファイルを生成する:

```markdown
---
name: <kebab-case-name>
description: >
  <1-2行の説明。いつ使うかを含める。>
---

# <スキル名>

<概要>

## 手順

### 1. <ステップ名>

<具体的な手順>
```

**書き方（コンテキスト節約。rules/agents にも同じ方針）**:

- 要点のみを箇条書きで書く。各行は「これが無いと判断を誤るか」で検る
- 判断に必要な場合だけ、1〜数行の簡単な具体例（最小の悪い例・良い例）を添える
- 背景・長い手順・大きなコード例は `references/` に分離し、本文はリンクのみ

### 3. テストケース設計

検証シナリオを設計する:

- 正常系: 期待通りの入力で期待通りの出力が得られるか
- 境界: 引数なし、不正な引数での振る舞い
- 既存スキルとの競合がないか

### 4. 試行

テストシナリオに基づいてスキルを試行し、問題があれば修正を繰り返す。

### 5. 配置

完成したスキルを `.claude/skills/` に保存する。

### 6. セキュリティ検証

SkillSpector でスキルの安全性を検証する:

1. `skillspector scan .claude/skills/<スキル名>/ --no-llm` を実行（静的解析）
2. スコア 50 以下（SAFE / CAUTION）: 検証通過
3. スコア 50 超（DO NOT INSTALL）: 検出された脆弱性を修正し、再スキャンする
4. `skillspector` が未インストールの場合はスキップし、手動確認をユーザーに案内する
