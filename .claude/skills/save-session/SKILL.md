# セッション保存

セッションの作業コンテキストを整理し、ユーザーに報告する。
整理した内容のうち次のセッションに要るものを、ファイルメモリの該当する project メモリに書く。

> claude-mem のような SessionEnd 自動記録はない。能動的にメモリファイルへ書く。
> セッションごとの日誌ファイルは作らない（記憶は話題ごとに 1 ファイル。規約は `memory.md`）。

## トリガー

以下のタイミングで呼ばれる（memory.md ルールで規定）:

- `/create-pr` 実行後
- `/loop` のループ完了後
- ユーザーがセッション終了を示唆したとき

## 手順

### 1. 差分サマリ生成

git の状態から作業内容を自動取得する:

- 現在のブランチ: !`git branch --show-current`
- main からのコミット: !`git log main..HEAD --oneline 2>/dev/null | head -10`
- 変更ファイル: !`git diff main...HEAD --name-only 2>/dev/null | head -20`

### 2. コンテキスト整理

以下を簡潔にまとめる（各項目2-3行以内）:

- **やったこと**: git log から自動抽出 + 補足
- **次のアクション**: 残タスクや次回最初にやるべきこと
- **判断ログ**: セッション中の重要な設計判断（あれば）
- **未解決事項**: ブロッカーや保留事項（あれば）

### 3. ユーザーへの報告

整理した内容をユーザーに提示する。以下の形式で出力する:

```text
## セッションサマリ

**ブランチ**: <ブランチ名>

### やったこと
<要約>

### 次のアクション
- [ ] <次にやること>

### 判断ログ（あれば）
- <判断>: <理由>

### 未解決事項（あれば）
- <ブロッカー>
```

### 4. メモリへの記録

報告した内容のうち、**リポジトリに書けない今の状況**だけをメモリに残す:

| 書くもの                                                    | 書き先                                                                            |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 進行中の作業（どこまで済んだか・残り）                      | 該当する `project_<slug>.md`                                                      |
| 決定待ちの論点（ユーザーへの質問・返事待ち）                | 同上                                                                              |
| いつ何を確かめるか（例: 「2026-10-31 にクリック率を見る」） | 同上                                                                              |
| セッション中に受けた指摘                                    | `feedback_<slug>.md`（`evolve: pending`。`memory.md` のフィードバック検知どおり） |

1. メモリディレクトリを求める:
   ```bash
   ROOT=$(dirname "$(git rev-parse --path-format=absolute --git-common-dir)")
   MEMDIR="$HOME/.claude/projects/$(echo "$ROOT" | sed 's#/#-#g')/memory"
   ```
2. `MEMORY.md` の索引と `grep -ril "<話題の語>" "$MEMDIR"` で、同じ話題の project メモリを探す
3. あれば Read してから追記・更新する（古くなった記述は直す。重複を作らない）。
   無ければ `project_<slug>.md` を新規作成し（frontmatter は `memory.md` の形式、
   **Why:** と **How to apply:** を付ける）、`MEMORY.md` に索引行を 1 行足す
4. 日付は「今日」「明日」ではなく絶対日付（YYYY-MM-DD 等）で書く
5. 手順・決まり・再利用できるやり方はメモリに書かない。`CLAUDE.md` / `AGENTS.md` /
   `.claude/skills/` の該当ファイルに書く（変更はユーザーに報告する）

記録後は `MEMORY.md` の索引（次のセッションで自動で読み込まれる）と
`grep -ril` で検索できる。
