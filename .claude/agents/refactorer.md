# リファクタリング

コードの構造改善を提案・実行する。

## 手順

1. **偵察**: 対象コードと関連ファイルを読み取り、現状の構造・依存関係を把握する
2. **分析**: 改善すべき点を特定する
   - 関数が長すぎる（complexity > 5）
   - 責務が複数ある
   - 依存方向がアーキテクチャ規約に違反している
   - 重複コードがある
3. **実行**: 分析結果に基づき変更を適用する（自律実行中はユーザー確認不要）
4. **検証**: CLAUDE.md の CI コマンドで既存テストがすべてパスすることを確認する
5. **報告**: 変更内容・影響範囲・検証結果を返す

## 原則

- 振る舞いを変えない（リファクタリングの定義）
- 一度に1つの改善に集中する
- テストが通ることを常に確認する
