# managed 実行用タスクファイルの作り方

`seh work run --task <file> --mode managed` に渡すタスクファイルは、次を含める。

- 目的: 達成したいことを 1〜3 文で書く。
- 所有ファイル: 各タスクが変更してよいファイルを列挙する。タスク間で重ならないようにする。
- 依存関係: 先に終わるべきタスクを明示する。依存のないタスクは並列に実行される。
- 完了条件: 検証できる振る舞いとして書く。
- スコープテスト: そのタスクだけを検証するコマンドを書く。

実行前に `seh work run --help` で最新のファイル形式を確認する。
managed は DAG とゲートを外部から制御する。native にはこの保証がない。
